# Demo artwork sources

The named-app artwork is used only for deterministic demo fixtures. It was retrieved
from Apple's public App Store metadata on July 25, 2026:

- [Instagram](https://apps.apple.com/us/app/instagram/id389801252)
- [TikTok](https://apps.apple.com/us/app/tiktok-videos-shop-live/id835599320)
- [Reddit](https://apps.apple.com/us/app/reddit/id1064216828)
- [YouTube](https://apps.apple.com/us/app/youtube/id544007664)

Production selections must use the privacy-preserving application tokens and labels
returned by Apple's Family Controls picker. The bundled demo artwork is not evidence
that any of these apps is installed or selected on a device.
